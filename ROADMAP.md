# Roadmap

This repository should compound over time into a practical personal AI/automation engineering platform rather than a collection of disconnected demos.

## Stage 1 — Foundations
- Repository context engineering for coding agents
- Repeatable local inference service
- Basic agent eval harness
- Standard project bootstrap conventions
- CI and observability baseline

## Stage 2 — Reliable agent workflows
- Tool-use and trajectory evaluation
- Approval gates and trust boundaries
- Subagents / orchestration patterns
- Structured plans, issues, and PR workflows
- Failure capture → regression eval loop

## Stage 3 — Personal automation platform
- General-purpose home agent
- Personal search/RAG and knowledge workflows
- Event → reason → propose → approve → execute → verify pattern
- Mobile-friendly interaction surfaces
- Auditability, secrets, and permissions

## Stage 4 — Home-lab integration
- Reproducible content/media services
- Monitoring, backup, restore testing
- Local AI services as shared infrastructure
- Infrastructure-as-Code / configuration management
- Remote administration and recovery

## Stage 5 — Compounding automation
- Agents that maintain repositories and infrastructure under clear policies
- Automated evals before model or prompt changes
- Cross-project reusable modules and templates
- Cost/performance benchmarking across local and cloud models
