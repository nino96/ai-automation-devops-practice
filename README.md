# AI + Automation + DevOps Practice

Monthly, hands-on practice repository for building practical AI leverage, agentic coding skills, general-purpose automations, and reproducible DevOps/home-lab systems.

## How this repository works

Each month lives under `months/YYYY-MM/` and contains a focused **4–6 hour curriculum**, selected resources, reproducible exercises, progress notes, and durable artifacts.

Repository-level files provide continuity:

- `AGENTS.md` — operating instructions for coding/automation agents updating this repo.
- `ROADMAP.md` — longer-term progression from foundations to reliable personal automation.
- `progress.md` — month-by-month status and carry-forward tracking.

## Principles

- Practice over news consumption.
- Reproducibility over one-off demos.
- Measured agent performance over vibes.
- Deterministic software controls for guarantees; LLMs for ambiguity.
- Prefer projects that compound into a coherent personal AI/automation/home-lab platform.
- Keep larger implementation projects in dedicated repositories and link them back here.
